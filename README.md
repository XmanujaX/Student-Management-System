Student Management System - PUSL2021

This is a Python Flask project with MySQL database.

## How to run:
1. Make sure you have XAMPP installed and running (Apache & MySQL).
2. Create a new database named 'student_db' in phpMyAdmin.
3. Import the provided 'student_db.sql' file into 'student_db'.
4. Install requirements: `pip install Flask PyMySQL`
5. Run the application: `python app.py`
